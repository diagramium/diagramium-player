# Contributing to diagramium-player

Thanks for helping. Bug reports, fixes, docs and new ideas are all welcome.

## Getting started

```bash
npm install
npm run dev        # demo page at http://localhost:5173 — pick an example or drop a .json
npm test           # builds, then runs the headless tests
npm run typecheck
```

Developing needs Node 22 or newer (the build tool and the test runner need it). Using the published package has no Node requirement.

## Where things live

| File | What it does |
| --- | --- |
| `src/adapter.ts` | Reads a Diagramium file into a normalised, laid-out diagram (no DOM needed). |
| `src/player.ts` | Draws it as SVG in a shadow root and runs the steps, events and styling. |
| `src/themes.ts` | The built-in theme presets. |
| `src/types.ts` | The public types: the file format and the player's options/events. |
| `src/shapes.generated.ts` | Icon and shape table, generated by maintainers from the editor — please don't edit by hand. |
| `tests/` | Headless tests (`node --test`) for the adapter. |
| `index.html`, `docs-sample/` | The live demo and the documentation sample (`npm run build:demo` builds both for GitHub Pages). |

## Pull requests

- Keep the player **dependency-free** at runtime and **private** — no network calls, no analytics, no cookies.
- Treat diagram files as untrusted: text goes in with `textContent`, never `innerHTML`, and colours pass `safeColor()`.
- Add or update a test in `tests/` when you change how files are read.
- Run `npm run typecheck` and `npm test` before opening the PR (CI runs both).
- One topic per pull request, with a short description of what changed and why.

By contributing, you agree that your contribution is licensed under the project's [MIT licence](LICENSE).

## Reporting bugs

Open an issue with the browser, what you expected, what happened, and — if you can — the diagram `.json` that shows it (remove anything private first).
