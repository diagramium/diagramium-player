The same documentation page, two ways

A made-up API guide, "How checkout works", written once. On the left it has the diagram most docs have: a picture at the top. On the right the same diagram is a Diagramium file played by diagramium-player, in step with the text.

Before

Static diagram

One image above eight sections. The reader scrolls away from it and has to match "step 5" to a box they can no longer see.

 After — diagramium-player

Animated, synced diagram

The diagram stays pinned above the text and builds up as you read, highlighting the box each section is about. Or press Play the tour and it walks you through.
