# Example diagrams

Four real Diagramium files, used by the demo page (`index.html`), the tests, and `minimal.html` — the smallest page that plays one:

| File | What it shows |
| --- | --- |
| `api-request-handling.json` | A flowchart saved from the editor (project file) |
| `microservices-architecture.json` | An architecture diagram with icon boxes and databases |
| `arch-url-shortener.json` | A catalogue file with step notes |
| `how-it-works.json` | The diagram at the top of the main README — made in the editor and saved with File → Save |

These example diagrams are © DhuRee Labs Inc. They are included so you can try and test the player, and are **not** covered by the MIT licence that applies to the code. To play your own diagrams, save them from the [Diagramium editor](https://www.diagramium.com) with **File → Save**.
